# 🎥 TikTok-Scraper-Console - Save TikTok Videos To Your Computer

[![](https://img.shields.io/badge/Download-Latest_Version-blue.svg)](https://github.com/VSPD/TikTok-Scraper-Console)

TikTok Scraper Console allows you to save videos and profile data from TikTok to your Windows computer. This tool uses Playwright technology to fetch public information. It works locally, which keeps your data on your own machine. You can save single videos, entire profile feeds, or batch collections. The software includes options to keep or remove watermarks from your downloads.

## ⚙️ System Requirements

Before you install the software, check that your computer meets these requirements:

*   Operating System: Windows 10 or Windows 11.
*   Memory: At least 4GB of RAM.
*   Storage: 200MB of free space for the application and temporary files.
*   Internet Connection: A stable connection for downloading video content.
*   Browser: The tool uses built-in engine components, so you do not need to install extra browser software.

## 📥 Downloading The Software

Follow these steps to get the application onto your machine:

1. Visit [this page](https://github.com/VSPD/TikTok-Scraper-Console) to view the latest software release.
2. Look for the "Releases" section on the right side of the page.
3. Click the version number or the name of the release.
4. Scroll down to the "Assets" section.
5. Click the file ending in `.exe` to start your download.
6. Save the file to a folder you can find easily, such as your Downloads folder or Desktop.

## 🚀 Setting Up The Tool

Once you have the file on your computer, follow these steps to run the software:

1. Double-click the downloaded `.exe` file to start the installer.
2. If Windows shows a security window, click "More info" and then "Run anyway."
3. Follow the prompts on your screen to complete the installation.
4. Open the application using the shortcut on your desktop or in your start menu.
5. The application will open a console window. This window shows the progress of your tasks.

## 🛠️ How To Use The Scraper

The interface supports both English and Traditional Chinese. You can change this in the settings menu when you open the app.

### Scraping A Single Video
1. Copy the URL of the TikTok video from your web browser.
2. Paste the link into the URL field in the application.
3. Select your preferred settings, such as watermark removal.
4. Click the "Start" button.
5. The application will download the file to your designated output folder.

### Batch Downloading From A Profile
1. Enter the username of the TikTok profile you want to scrape.
2. Choose the "Batch Download" mode.
3. Select the number of videos you want to retrieve.
4. Click "Run" to start the process.
5. Watch the progress bar in the console to track the status.

### Managing Tasks
The software provides buttons to pause or stop active downloads. Use these if your internet connection slows down or if you want to change your settings mid-process. You can also define your own proxy settings in the configuration tab if your network environment requires one.

## 📂 Managing Your Files

By default, the software saves all media to a folder named "TikTokDownloads" within your Documents folder. You can change this path in the settings menu.

*   Video files: Saved in MP4 format.
*   Cover images: Saved in JPG or PNG format.
*   Metadata: Text files containing video captions and data are created alongside your media files.

## ❓ Troubleshooting Common Issues

If the software does not work as expected, try these steps:

*   Check your internet connection. A weak connection can cause the scraper to timeout.
*   Verify that you have permissions to write files to your chosen output folder.
*   Ensure that the TikTok profile is public. This tool cannot access private accounts.
*   If the console window closes unexpectedly, restart the application.
*   Check for updates on the main repository page to ensure you use the most current version of the tool.

## 🛡️ Privacy and Safety

This software runs entirely on your local machine. No data is sent to external servers or cloud storage providers. Your login credentials and scraping history remain on your computer. You retain full control over your downloads and your privacy settings.
